# qorvyx/homebrew-tap

Homebrew formulae for [tmpmail](https://github.com/qorvyx/tmpmail), temporary email from the terminal.

```sh
brew install qorvyx/tap/tmpmail
```

Use the full name: Homebrew's own `tmpmail` is a different project.
The formula installs the prebuilt release binary for macOS (Intel, Apple silicon) and Linux
(x86_64, aarch64), with shell completions and man pages. It is updated automatically on each
tmpmail release.
